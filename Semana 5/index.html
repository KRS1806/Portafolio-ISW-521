Sobre mí

Soy un desarrollador enfocado en soluciones empresariales con C# y .NET, trabajando en arquitecturas limpias y sistemas robustos para el ecosistema NCQ.

Me interesa la arquitectura de software, los patrones de diseño y el desarrollo de APIs REST. Fuera del trabajo, exploro el desarrollo web frontend y aplico lo aprendido en proyectos académicos del curso ISW-521.

Proyectos

  • QUPOS – Módulo de Autorización de Órdenes de Compra

    C# · WinForms · DevExpress · PostgreSQL · Npgsql

    Flujo completo de autorización de órdenes de compra dentro del ERP QUPOS. Incluye validación de pedidos especiales (ValidarPedidoEspecial), lectura de filas enfocadas en grillas DevExpress (GetFocusedRowCellValue) y manejo parametrizado de consultas con NpgsqlParameter[] para evitar inyección SQL.

    Ver proyecto →

  • NotificationCenter – Alertas de Stock Mínimo

    C# · Windows Service · Amazon SES · PostgreSQL · Npgsql

    Servicio de Windows que consulta la tabla inventario con criterios duales: existencia_minima y minimo_dias_inventario × promedio_venta. Persiste historial en notificaciones_historial, controla ventanas de tiempo con YaEjecutoNotificacionHoy y envía alertas por correo vía Amazon SES.

    Ver proyecto →

  • FE_API – Facturación Electrónica Hacienda CR

    .NET · Clean Architecture · FluentValidation · XML Signing · Swagger

    API REST en .NET con Clean Architecture para integración con el sistema de facturación electrónica del Ministerio de Hacienda de Costa Rica. Implementa validadores seccionados con FluentValidation (ValidateIssuer, ValidateReceiver, ValidateInvoiceDetails), firma digital XML migrada de Python a C# mediante XmlSigningService y CertificateService.

    Ver proyecto →

  • QUPOS – Gestión de Familias de Artículos

    C# · WinForms · Patrón Factory · DevExpress · PostgreSQL

    Refactorización del módulo de artículos en QUPOS aplicando el patrón FamiliaFactory e interfaces segregadas (IFamilia / IFamiliaGestora). Separación de responsabilidades entre lectura y escritura, con controles DevExpress (SpinEdit, XtraTabControl) y lógica de porcentajes por familia de productos.

    Ver proyecto →

  • QUPOS – Módulo de Inventario y Reportes

    C# · CrystalDecisions · PostgreSQL · DLL Integration

    Integración de InventarioB.dll en el módulo de inventario de QUPOS para generación de reportes con CrystalDecisions. Consultas SQL con CASE WHEN para manejo de valores nulos en existencias, reporte de artículos bajo stock crítico y exportación de resultados desde grillas DevExpress.

    Ver proyecto →

  • Portafolio Web – ISW-521

    HTML5 · CSS3 · JavaScript · Responsive Design · WCAG
